Name line ranges of a code node with `range sql.copy1 lines=3-6 "label"` or `match="regex" span=n`. A range draws a tinted band, a margin bar and a label without moving anything, and `sql.copy1` works in `edge` (the line meets the range's middle line), `note near=` and `state`.
