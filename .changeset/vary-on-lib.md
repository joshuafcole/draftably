`draftably/lib` exports `vary`, the call behind `draftably vary`: layout and routing variants of a source, each compiled, routed, measured and drawn (`drawn` holds each one's source and SVG), ranked against the source as it is, with `fit`, `prefer`, `scope`, `limit` and `budget`. `applyEdits`, `drawScene`, `improves` and `FITS` come with it. No file is read or written, so a host can run it in a page or a compiled helper.
